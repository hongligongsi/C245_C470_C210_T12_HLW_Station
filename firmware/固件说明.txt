T12 / HLW C245 / C210 / C470 焊台固件包说明
==================================================
固件版本：v1.1.0
编译提交：a76fa39
发布日期：2026-11-03


一、本目录内容
--------------------------------------------------
本目录存放可直接烧录的固件镜像（.bin），共三个版本。三者业务代码、界面、
PID、保护逻辑完全一致，仅"输入设备 / 开机方式"不同。

命名规则：station_<类型>_v<版本>_<git提交短号>.bin

  station    设备名（焊台）
  类型       encoder = 编码器版, button = 三键版, auto = 开机即用版
  版本       固件版本号（源码 src/board.h 中的 FW_VERSION）
  提交短号   编译时仓库的 git 提交号，用于区分固件来源

二、三个固件版本
--------------------------------------------------
1) station_encoder_v1.1.0_a76fa39.bin
   编译环境：hc32f460jeta
   输入设备：EC11 旋转编码器（PA0/PA1/PA2）
   操作方式：旋转调温，短按循环快捷温度，长按进入菜单
   烧录命令：.\flash.ps1

2) station_button_v1.1.0_a76fa39.bin
   编译环境：hc32f460jeta-btn
   输入设备：三个按键（加 / 减 / 确认，默认与编码器同座：
             A 脚=加, B 脚=减, C 脚=确认）
   烧录命令：.\flash.ps1 -Button

3) station_auto_v1.1.0_a76fa39.bin
   编译环境：hc32f460jeta-auto
   输入设备：无。PA0/PA1/PA2 不初始化、不上拉、不扫描，完全交给外部电路/悬空
   开机行为：上电自动进入开机状态，固定 350°C 加热；
             无快捷温度、温度不可调，屏幕不显示 CH1~CH3
   烧录命令：.\flash.ps1 -Auto

三、共同参数
--------------------------------------------------
主控芯片：HC32F460JETA（512KB Flash / 192KB SRAM，Cortex-M4F）
默认温度：350°C（编码器版/三键版上电取快捷温度第 2 档；即用版固定此值）
可调范围：100 ~ 450°C，步进 5°C（即用版不可调）
快捷温度：300 / 350 / 400°C（编码器版/三键版主页短按循环；即用版无此功能）
BOOST    ：当前设定 +48°C（受温度上限钳位）
待机温度：100°C（待机时间默认关闭，需滚珠开关硬件支持）
休眠时间：编码器版/三键版默认 10 分钟（菜单可改 1~120 分钟）；
          开机即用版固定 5 分钟
功率上限：70%（菜单可改 10~100%；识别为 C210 时该型号参数自动 60%）
屏幕型号：LCD_TYPE=3（320×240 横屏，ST7789V2，软件 SPI）
资源占用：Flash 约 53KB（10.4%），RAM 约 168KB（85.5%，主要为显示帧缓冲）
保护功能：欠压 17V / 过压 50.5V / 470°C 绝对强关 / 480°C 超温锁定 /
          过流 6A / 无温升看门狗（传感器或加热回路故障 8s 锁停）
参数存储：片内 Flash 模拟 EEPROM，CRC 校验，断电不丢（设置结构 v3）

四、v1.1.0 更新内容
--------------------------------------------------
1. 温度换算改为查表：内置 NIST K 型分度表（0~500°C，10°C 步进）+ 线性插值，
   冷端改为"电动势相加"补偿。替代旧版固定 41µV/°C 线性近似，
   400°C 附近约 6°C 的固有偏低被消除。
   需要回退旧算法时可用编译宏 -DTC_LINEAR_UV_PER_C=41。
2. 采样后增加 10 点滑动窗口（约 50ms）：窗口均值用于温度显示与超温/看门狗
   判定，控制环仍使用相位滞后小的快值，回温速度不受影响。
3. 470°C 绝对强关：越过即跳过 PID 直接关断加热，任何目标温度 / BOOST /
   参数异常都无法越过该线；480°C 仍锁定 FAULT_OVERTEMP 需手动清除。
4. 手柄参数随机型装载：识别到 T12 / C210 / C245 后自动套用该型号的
   P / I / D、功率上限、温度上限（C210 出厂 60% / 400°C）。
   工具设置里新增「手柄参数」子菜单；直接改全局 P/I/D 会自动关闭「PID 跟随」。
5. 故障周期报警：故障期间蜂鸣器按超温/传感器三连鸣、其余双鸣循环，
   2 秒一轮。可选硬件报警输出（-DPIN_ALARM=PAx，默认未启用）。
6. 「关于本机」改为全屏信息页：固件版本、编译时间、主控、配置版本、
   当前手柄、供电电压（高压状态标注）、焊头温度、环境温度、运行时长。
7. 补齐中文字库（146 字）：修复此前"固件版本""供电电压"等文字缺笔画、
   显示不完整的问题。
8. 故障页汉字支持 3 倍放大显示。

五、升级须知
--------------------------------------------------
设置结构由 v2 升级到 v3，首次上电会自动恢复一次出厂默认值（含新增字段），
属预期行为。之后升级固件不再清设置；如需重新套用默认值，
请在菜单执行「系统重置」。

六、编译命令（在项目根目录执行）
--------------------------------------------------
pio run                        # 编码器版
pio run -e hc32f460jeta-btn    # 三键版
pio run -e hc32f460jeta-auto   # 开机即用版

产物路径：.pio/build/<环境名>/firmware.bin

七、手动烧录（不使用脚本时）
--------------------------------------------------
pyocd list
pyocd load --target hc32f460xe -O connect_mode=under-reset <固件文件>

条件：CMSIS-DAP 调试器接好 SWCLK / SWDIO / GND，主板按规格供电。
PowerShell 若提示禁止运行脚本，可用：
powershell -ExecutionPolicy Bypass -File .\flash.ps1

八、注意事项
--------------------------------------------------
1. 三个固件共用同一套设置存储。升级固件不会清除已保存的设置；
   只有设置结构版本变化时才会恢复一次出厂默认值（详见第五节）。
2. 开机即用版没有任何输入设备：休眠 5 分钟后停热、出现故障后都无法
   唤醒或清除，只能断电重启。用于固定温度、免操作场景时请注意这一点。
3. 固件按屏幕型号编译，烧录前必须确认 LCD_TYPE 与实际屏幕分辨率一致，
   否则可能白屏或花屏。
4. 供电与手柄必须匹配：T12 / C210 / C245 只能 24V（18~34V）；
   48V（40~52V）只允许 C245/C470 大功率芯，接错会报 V/TIP ERR 并停热。
5. .bin 为纯二进制镜像，不含调试信息；需要调试请使用 .pio/build 下的
   firmware.elf 配合 pyOCD 进行。
6. 引脚分配、手柄接口等硬件说明见项目根目录 README.md「硬件」章节。
7. 本版未做上机验证（编译通过 + 算法离线复算）。首次通电建议先用
   低压电源配常规手柄，重点确认温度读数、切型号时参数是否切换、
   470°C 是否确实断热。
