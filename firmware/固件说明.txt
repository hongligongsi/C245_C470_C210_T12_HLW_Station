T12 / HLW C245 / C210 / C470 焊台固件包说明
==================================================
固件版本：v1.2.2
发布日期：2026-11-04


一、本目录内容
--------------------------------------------------
本目录存放可直接烧录的固件镜像（.bin），共三个版本。三者业务代码、界面、
PID、保护逻辑完全一致，仅"输入设备 / 开机方式"不同。

命名规则：station_<类型>_v<版本>_<git提交短号>.bin

  station    设备名（焊台）
  类型       encoder = 编码器版, button = 三键版, auto = 开机即用版
  版本       固件版本号（源码 src/board.h 中的 FW_VERSION）
  提交短号   编译时仓库的 git 提交号，用于区分固件来源

二、三个固件版本
--------------------------------------------------
1) station_encoder_v1.2.2_<hash>.bin
   编译环境：hc32f460jeta
   输入设备：EC11 旋转编码器（PA0/PA1/PA2）
   操作方式：旋转调温，短按循环快捷温度，长按进入菜单
   烧录命令：.\flash.ps1

2) station_button_v1.2.2_<hash>.bin
   编译环境：hc32f460jeta-btn
   输入设备：三个按键（加 / 减 / 确认，默认与编码器同座：
             A 脚=加, B 脚=减, C 脚=确认）
   烧录命令：.\flash.ps1 -Button

3) station_auto_v1.2.2_<hash>.bin   （开机即用版 / 无键版）
   编译环境：hc32f460jeta-auto
   输入设备：无。PA0/PA1/PA2 不初始化、不上拉、不扫描，完全交给外部电路/悬空
   开机行为：上电自动进入开机状态，直接加热到「开机温度」（出厂 350°C）
   参数调整：不需要任何额外硬件，手柄拔插就是"按键"——
             连插 3 次（6s 内）进入「无键设置」，可改 开机温度 / 待机温度 /
             待机时间 / 休眠时间 / 功率上限；故障拔插 1 次复位；
             休眠拔插 1 次唤醒
   烧录命令：.\flash.ps1 -Auto


三、无键设置（即用版专属，v1.2.2 新增）
--------------------------------------------------
进入方式：正常工作或无工具状态下，6 秒内连插 3 次手柄（每次插一下就拔）。

设置页共 5 项，每项停留 3 秒，自动逐项推进：

  1. 开机温度   100~450°C   步进 10°C（上电即加热到该值，同时写入快捷温度第 2 档）
  2. 待机温度   50~300°C    步进 5°C
  3. 待机时间   0~30 分钟   步进 1 分钟（0=不启用）
  4. 休眠时间   5~60 分钟   步进 5 分钟（到期停热，拔插唤醒）
  5. 功率上限   10~100%     步进 5%（默认 70%）

手势（屏幕上有三行提示 + 底部 3 秒倒计时条）：
  快插快拔（插入不到 0.9 秒就拔出）= 当前项 +1 步
  插入并保持（插着不动 1.4 秒以上）= 当前项 -1 步
  停手 3 秒 = 保存本项并进入下一项；全部走完显示「已保存」

说明：
  - 数值到上下限后按步进环绕（450 再加一档回到 100），加/减都能调到任意档；
  - 设置期间强制停热，手柄插着也不会加热；
  - 某项不想改就停手让它自己走，全程约 15 秒自动走完退出；
  - 改动立即写入 Flash，断电不丢，无需重新烧固件。


四、共同参数
--------------------------------------------------
主控芯片：HC32F460JETA（512KB Flash / 192KB SRAM，Cortex-M4F）
默认温度：350°C（上电取快捷温度第 2 档；可用 -DCFG_BOOT_TEMP=xxx 定制出厂值）
可调范围：100 ~ 450°C，步进 5°C（即用版在无键设置里调，步进 10°C）
快捷温度：300 / 350 / 400°C（编码器版/三键版主页短按循环；即用版开机温度=第 2 档）
BOOST    ：当前设定 +48°C（受温度上限钳位）
待机温度：100°C（待机时间默认关闭，需滚珠开关硬件支持）
休眠时间：编码器版/三键版默认 10 分钟；开机即用版默认 5 分钟
          （可用 -DCFG_SLEEP_MIN=n 定制出厂值）
系统亮度：1~10 档（每档 10% 背光占空比，默认 10 档）
功率输出：70%（菜单可改 10~100%；识别为 C210 时该型号参数自动 60%）
屏幕型号：LCD_TYPE=3（320×240 横屏，ST7789V2，软件 SPI）
资源占用：Flash 54.7~55.4KB（10.7%~10.8%），RAM 约 168KB（85.5%，
          主要为显示帧缓冲）
保护功能：欠压 17V / 过压 50.5V / 470°C 绝对强关 / 480°C 超温锁定 /
          过流 6A / 无温升看门狗（传感器或加热回路故障 8s 锁停）
参数存储：片内 Flash 模拟 EEPROM，CRC 校验，断电不丢（设置结构 v3）

五、v1.2.2 更新内容
--------------------------------------------------
1. 【重要】开机即用版新增「无键设置」：手柄拔插手势 = 唯一输入，
   不接编码器/按键也能修改 开机温度 / 待机温度 / 待机时间 / 休眠时间 /
   功率上限，改动存 Flash（详见第三节）。旧版"固定 350°C 不可调"的问题解决。
2. 即用版手势兼作系统操作：故障页拔插 1 次清除故障；休眠中拔插 1 次唤醒
   （旧版休眠后只能断电重启）。
3. 即用版底部提示带 / 无工具页 / 休眠页 / 故障页文案全部改为拔插手势说明，
   屏幕会提示当前该做什么动作。
4. 新增出厂参数编译宏：-DCFG_BOOT_TEMP（开机温度）、-DCFG_SLEEP_MIN（休眠
   时间），批量出货可一机一参；不影响已保存的设置。
5. 设置期间（无键设置页打开时）强制停热，防止边改参数边烧红烙铁头。
6. 字库扩充至 165 字（新增 键/目/拔/秒/下/次/减/持），预览页同步。
7. docs/UI预览.html 新增「无键设置」页面模拟（工况按钮或 #nokey 深链可查看）。

六、升级须知
--------------------------------------------------
设置结构保持 v3，本版升级不会清除已保存的设置；如需重新套用默认值，
请在菜单执行「系统重置」（即用版刷机后 Flash 中仍是旧设置，属正常现象）。

七、编译命令（在项目根目录执行）
--------------------------------------------------
pio run                        # 编码器版
pio run -e hc32f460jeta-btn    # 三键版
pio run -e hc32f460jeta-auto   # 开机即用版

产物路径：.pio/build/<环境名>/firmware.bin

八、手动烧录（不使用脚本时）
--------------------------------------------------
pyocd list
pyocd load --target hc32f460xe -O connect_mode=under-reset <固件文件>

条件：CMSIS-DAP 调试器接好 SWCLK / SWDIO / GND，主板按规格供电。
PowerShell 若提示禁止运行脚本，可用：
powershell -ExecutionPolicy Bypass -File .\flash.ps1

九、注意事项
--------------------------------------------------
1. 三个固件共用同一套设置存储。升级固件不会清除已保存的设置；
   只有设置结构版本变化时才会恢复一次出厂默认值。
2. 开机即用版没有任何输入设备：休眠后拔插手柄唤醒、故障拔插复位、
   连插 3 次进设置。若手柄/支架无法拔插，则只能断电重启。
3. 固件按屏幕型号编译，烧录前必须确认 LCD_TYPE 与实际屏幕分辨率一致，
   否则可能白屏或花屏。
4. 供电与手柄必须匹配：T12 / C210 / C245 只能 24V（18~34V）；
   48V（40~52V）只允许 C245/C470 大功率芯，接错会显示「电压过低 / 电压过高」
   并停止加热。
5. 手柄配线颜色因批次/厂家而异，接线请参照 README「手柄接线」章节的
   接线图并用万用表核实针脚功能，勿只凭线色。
6. .bin 为纯二进制镜像，不含调试信息；需要调试请使用 .pio/build 下的
   firmware.elf 配合 pyOCD 进行。
7. 引脚分配、手柄接口等硬件说明见项目根目录 README.md「硬件」章节。
8. 本版为编译通过 + 算法离线复算 + 预览页逐屏渲染核对，未做整机上机
   验证。「无键设置」的手势节奏（快插/保持/连插 3 次）建议上电先空载
   （不接加热电源）试一遍再投入正常使用。
