参数调整说明（PID 与功率）

· 比例项（P）：决定 PID 温差比例系数，取值大小影响加热速度，调整不当会引起温度振荡。
· 积分项（I）：温差的积分系数，影响测温准确性和误差。
· 微分项（D）：温差的微分系数，决定预测性判断，调整不当会引起过冲或回温缓慢。
· 控制带宽：PID 起控温差系数，温差接近某一数值 PID 才起控，未到达前全速加热，可提高回温速度；取值不当容易造成过冲。
· 实测：PI 项增加会提高回温加热速度，但更容易过冲。默认值 25 / 0.3 / 15；偏保守的自用值 20 / 0.1 / 18（牺牲速度换稳定性）。
· 各家的烙铁头内阻及热电偶阻值不同，同样的参数表现会不同；无测试设备时推荐使用默认值。
· 功率输出默认 70%。可用 P=IU、P=I²R、P=U²/R 换算；100% 为不限制功率，过高功率可能降低烙铁头寿命，推荐默认值。
· 滚珠开关：待机时间为 0 时此项无意义；若要使用需把待机时间设为非 0（推荐 1–3 分钟）。
