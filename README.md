# T12 / HLW C245 / C210 智能焊台固件

基于 **HC32F460JETA**（Cortex-M4F, 512KB Flash / 192KB SRAM）的通用 T12 / HLW C245 / C210（兼容 C470 手柄座）焊台固件，PlatformIO + Arduino 框架开发。

带实时温度/功率曲线、树状设置菜单、片内 Flash 参数掉电保存、可视化校准与完善的软硬件保护。

## 功能特性

- **多手柄支持**：T12 / HLW C245 / HLW C210 / HLW C470，通过手柄座 GET_ID 电阻自动识别型号（C210 支持 24V 供电）
- **双压自适应**：24V 输入 → **245 状态**，48V 输入 → **470 状态**（C470 大功率芯）；电压前馈标称随状态自动切换，顶栏型号跟随显示 C245/C470
- **彩屏 UI**：支持 0.96" 80×160（ST7735）、1.14" 135×240、1.3/1.54" 240×240、2.0~3.2" **320×240 横屏**（ST7789V2，软件 SPI）
- **实时曲线**：温度（蓝线）+ 功率（绿线）双波形，左轴 0-480°C / 右轴 0-100% 刻度网格，直观判断回温与过冲
- **全程 PID 控温**：积分分离（大温差全速加热）、微分先行、条件积分抗饱和、超温软刹车、供电电压前馈（换电源功率一致）；P / I / D / 控制带 / 功率上限全部菜单可调
- **实时遥测**：输入电压 V、加热电流 A、实时功率 W（U×I）
- **3 组快捷温度**：主页短按一键循环，当前通道高亮
- **自动状态机**：正常加热 / BOOST 一键升温 / 待机保温 / 支架休眠 / 时间休眠停热，支持手柄震动（滚珠）开关唤醒
- **可视化校准**：全屏实时校准页（V / I / P / T + 曲线），支持电压系数、冷结偏移（CJC）、350°C 单点温度增益（T CAL）
- **保护功能**：欠压 17V / 过压 50.5V / 超温 480°C / 过流 6A / 无烙铁头检测 / 大功率无温升传感器看门狗（热电偶短路、运放或 MOS 故障 8s 内锁停）；识别为 C210 时输出自动钳位 60% 防细发热芯过载
- **持久化**：所有设置存片内 Flash 末扇区（模拟 EEPROM），CRC 校验 + 字段钳位
- **树状中文逻辑菜单**（英文标签适配 5×7 ASCII 字库）：旋钮滚动 / 短按选择编辑 / 长按返回
- 软件 PWM 背光 1~100% 可调、蜂鸣器开关

## 硬件

主控：**HC32F460JETA LQFP48**，依据 `SCH_T12_HLW470-245-210_V1.7-高压版` 原理图。

| 功能 | 引脚 | 说明 |
|---|---|---|
| EC11 编码器 A/B/按键 | PA1 / PA0 / PA2 | 低有效，RC 滤波 |
| HLW 换芯开关 | PA3 (HLW_SW) | 低有效，300ms 消抖停热 |
| HLW 休眠线 | PA4 (HLW_SLE) | 低有效 |
| 手柄 ID 识别 | PA5 (GET_ID) | 板内上拉三档：接地=C210 / 经 10K=T12 / 悬空=C245 |
| 加热电流采样 | PA6 | 5mΩ + 增益 20 运放 |
| 烙铁头温度 | PA7 (T12-AD) | 热电偶运放增益 ≈212.77 |
| 输入电压采样 | PB0 | 47k / 可调下电阻分压 |
| T12 支架休眠 | PA8 (SLEEP) | 低有效 |
| 加热 PWM | PA9 | TIMA1 硬件 PWM，1kHz |
| 屏幕 CS/CLK/SDA/DC/RST | PA14 / PA15 / PB4 / PB5 / PB6 | 软件 SPI |
| 背光 | PB9 | 软件 PWM，100Hz |
| 蜂鸣器 | PB8 | 2.7kHz 无源 |
| 震动/滚珠开关 | `PIN_VIBRATION`（编译期可选） | V1.7 板默认未引出 |

### 手柄接线（GX16-5 五芯航空座）

| 针脚 | 功能 | 线色（C210/C245） | 线色（T12） |
|---|---|---|---|
| 1 | 震动开关（仅 T12 有） | — | 蓝 |
| 2 | 热电偶温度 ADC | 黄 | 黄 |
| 3 | 型号 ID | 绿 | 绿 |
| 4 | 电源负极（GND） | 红 | 红 |
| 5 | 电源正极（24V） | — | — |

三种手柄的 ID 档位由手柄内部接线决定，无需外部跳线：

| 手柄 | ID 线接法 | 板上 GET_ID 读数（12bit） |
|---|---|---|
| **HLW C210** | ID 直接接地 | ≈ 0 |
| **T12** | ID 经 10K 电阻接地 | 居中（上拉 10K 时 ≈ 2048） |
| **HLW C245** | ID 悬空 | ≈ 满量程（4095） |

> C210/C245 接头内部无震动开关，靠支架休眠线（PA8）或休眠时间进入休眠；T12 手柄的滚珠开关接针脚 1，配合 `PIN_VIBRATION` 编译宏使用。

### 供电电压与手柄匹配（24V/48V 双压）

高压版主机支持 24V / 48V 双压输入，固件按「手柄型号 × 输入电压」交叉校验，组合不匹配立即报错停热：

| 手柄（ID 档） | 输入电压 | 状态 |
|---|---|---|
| C245（悬空 ID） | 18 ~ 34V | **245 状态**（24V 满功率基准） |
| C245（悬空 ID） | 40 ~ 52V | **470 状态**（48V 满功率基准，顶栏显示 C470） |
| T12 / C210 | 18 ~ 34V | 正常 24V 工作 |
| 任意组合 | 34 ~ 40V 之间 / >52V / <18V | **V/TIP ERR 故障**，停止加热 |

- 匹配校验在上电 1s 后启动（避开 ID 消抖期），运行中持续监测；电压恢复匹配 1s 后故障自动清除
- **保护意义**：防止 48V 电源误插到 24V 发热芯（T12/C210/C245）造成立即烧毁；36V 等两窗口之间的电压视为异常输入
- 470 状态下电压前馈标称自动切换为 48V，同一组 PID 参数在两种状态下控温增益一致
- 窗口阈值可用编译宏覆盖：`-DVTIP_LO_24= -DVTIP_HI_24= -DVTIP_LO_48= -DVTIP_HI_48=`（单位 V）

## 编译

1. 安装 [PlatformIO](https://platformio.org/)（VS Code 插件或 CLI）
2. 克隆并进入工程目录
3. 编译：

```bash
pio run
```

平台与工具链会自动安装（社区平台 `platform-hc32f46x`、arm-none-eabi-gcc 12.3.1）。

### 屏幕型号切换

在 `platformio.ini` 的 `build_flags` 中修改 `LCD_TYPE`：

| 值 | 分辨率 | 控制器 | 方向 |
|---|---|---|---|
| 0（需自行切回） | 80×160 | ST7735 | 竖屏 |
| 1 | 135×240 | ST7789 | 竖屏 |
| 2 | 240×240 | ST7789 | 方屏 |
| **3（默认）** | **320×240** | **ST7789V2** | **横屏** |

若横屏画面方向颠倒/镜像，加编译宏覆盖：`-DLCD_MADCTL=0xA0`（备选 0xE0 / 0x20）。
屏幕批次若存在偏移，可用 `-DLCD_X_OFFSET=` / `-DLCD_Y_OFFSET=` 调整。

### 输入设备：编码器 / 三键双固件

输入设备为编译期选择，两种固件的界面、菜单、行为完全一致：

| 环境 | 输入设备 | 构建 | 产物 |
|---|---|---|---|
| `hc32f460jeta`（默认） | EC11 旋转编码器 | `pio run` | `.pio/build/hc32f460jeta/` |
| `hc32f460jeta-btn` | 三键：加 / 减 / 确认 | `pio run -e hc32f460jeta-btn` | `.pio/build/hc32f460jeta-btn/` |

按键版操作语义与编码器一一对应：

| 按键 | 单击 | 长按 |
|---|---|---|
| 加 / 减 | 调节一步 | 连发（350ms 后起步，100ms/步） |
| 确认 | 选择/进入/确认/开关 | 返回上级 / 退出 / 解除休眠 |

按键版默认与编码器共用同座引脚（A=加，B=减，C=确认），接线不同时可用 `-DBTN_UP_PIN= -DBTN_DOWN_PIN= -DBTN_OK_PIN=` 覆盖。烧录时把 `firmware.bin` 路径换成对应环境目录即可。

### 震动开关

手柄带滚珠/震动开关时，在 `build_flags` 增加 `-DPIN_VIBRATION=PAx`，并在工具设置中把「待机时间」设为非 0、「VIB SW」置 ON；晃动手柄即阻止/退出待机（休眠仍需长按解除）。

## 烧录

本工程使用 pyOCD + CMSIS-DAP 调试器（under-reset 连接）：

```bash
pyocd load --target hc32f460xe -O connect_mode=under-reset .pio/build/hc32f460jeta/firmware.bin
```

或在 PlatformIO 中执行 Upload（使用 platformio.ini 中配置的同一命令）。

| 场景 | 旋转编码器 | 短按 | 长按 |
|---|---|---|---|
| 主页 | 调温（按步进，自动开机/唤醒） | 循环 3 组快捷温度 | 进入菜单 |

| 休眠中 | — | — | 解除休眠 |

### 自动状态机说明

优先级从高到低：故障 → 无烙铁头/换芯 → 未开机 → 休眠 → 待机 → BOOST → 正常加热。

| 状态 | 行为 | 进入条件 | 退出方式 |
|---|---|---|---|
| 待机 STANDBY | 保温在「待机温度」（默认 100°C） | 支架休眠线触发，或待机时间到期 | 手柄操作唤醒（震动/旋钮/按键） |
| 休眠 SLEEP | 停止加热 | 待机状态持续「休眠时间」（默认 30min）未解除 | 仅长按编码器唤醒 |
| BOOST | 目标温度 +50°C 强化加热 | 工具设置中开启后按 HOME 键触发 | 超时自动退出或再次短按 |

> 时间逻辑为叠加：待机时间 = 震动开关最后一次操作到进入待机的时长；休眠时间 = 进入待机后再计时多久进入休眠。C210/C245 无震动开关时把「待机时间」设为 0，仅用支架休眠线 + 休眠时间。

### PID 参数与调参指南

默认 **P=25 / I=0.3 / D=15 / 控制带=25°C**。各项意义：

| 参数 | 作用 | 调整不当的后果 |
|---|---|---|
| **P（比例）** | 温差比例系数，决定加热速度 | 过大引起温度振荡 |
| **I（积分）** | 温差积分系数，消除稳态误差、影响测温准确性 | 过大易过冲；不建议设 0 |
| **D（微分）** | 温差变化率预测，决定预判强度 | 过大过冲、过小回温缓慢 |
| **控制带** | 温差超过此值全速加热（积分分离），提高回温速度 | 取值不当易过冲 |
| **功率上限** | 输出占空比百分比上限，默认 70% | 100% 为不限功率，过高缩短烙铁头寿命 |

经验参考：默认值（25/0.3/15）回温快但偏激进；保守可试 **20/0.1/18**，用回温速度换稳定性。实测提高 P、I 都能加快回温但更容易过冲。注意各家烙铁头内阻与热电偶阻值不同，同样参数表现会有差异；有外部测温设备时可进入校准菜单标定，无设备保持默认即可。

功率参考：实际功率按 P = U·I = I²R = U²/R 计算（R 为发热芯冷阻），屏幕 Power 一栏即 U×I 实时值。

### 控温算法细节

控制周期 50ms（20Hz），采样周期 5ms；温度通道在每个采样 burst 内取 8 次排序后最低 3 次平均（只取加热关断相的干净数据），再经一阶 IIR 滤波。

- **积分分离**：|误差| > 控制带时全速加热、不累加积分，兼顾回温速度与小误差稳定性
- **微分先行（derivative on measurement）**：微分项仅对实测温度求导，快捷切温/改设定值不会产生微分冲击
- **条件积分抗饱和（clamping anti-windup）**：PID 输出已饱和且误差仍推向饱和方向时暂停积分，抑制超调
- **软刹车**：实测温度超过目标 5°C 立即关断并清积分，早于 480°C 硬件式保护
- **供电电压前馈**：加热丝功率 P = D·U²/R，最终占空比按 `(24V/Vbus)²` 补偿（系数上限 4×）。同一组 PID 在 19V 笔记本电源与 24/32V 台机电源下的实际加热功率一致；24V 时系数为 1，行为与无补偿完全相同。标称电压可用 `-DNOMINAL_VBUS=xx` 覆盖
- **温度信号合理性检测**：占空比 >50% 持续 8 秒而温升不足 5°C 时锁定 `SENSOR ERROR`（热电偶短路到地、运放损坏或加热 MOS 失效），需手动清除

### 校准方法

进入「校准」菜单，选择任一项进入全屏校准页：

- **VBUS K**：万用表测实际供电电压，旋转旋钮使屏幕 Voltage 与万用表一致
- **CJC**：冷态下根据实测室温修正冷结偏移（-30~+30°C）
- **T CAL**：以 350°C 为校准点，配合外置测温设备修正温度增益（80~120%，100% = 不修正）

短按保存并写入 Flash，改动立即生效。

### 手柄 ID 分档

GET_ID ADC（12bit，板内上拉）三档判定：ID 接地 → **C210**（raw ≈ 0）；ID 经 10K 电阻接地 → **T12**（raw 居中）；ID 悬空 → **C245**（raw ≈ 满量程）。
默认阈值：raw < 400 → C210；< 3000 → T12；≥ 3000 → C245。
如与实际手柄不符，实测三个手柄插上后的 GET_ID 原始读数，通过编译宏覆盖：

```
-DTIPID_TH_C210=实测值 -DTIPID_TH_C245=实测值
```
